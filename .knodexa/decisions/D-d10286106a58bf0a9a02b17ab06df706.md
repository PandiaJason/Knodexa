## Rationale
Preserve the correctness of transactional snapshot replacement while eliminating writes and parsing for unchanged records. Persist record hashes, canonical bytes, and edge ownership. Same-mtime edits remain detectable; shared edges survive edits to one owner; duplicates and malformed input roll back. Benchmarks on 1000 data records show 3.54x faster unchanged sync and 2.89x faster one-task edit.

## Constraints
- Canonical files remain authoritative
- Never silently retain removed constraints or deleted nodes
- Keep rollback behavior for malformed input and duplicate IDs

## Rejected alternatives
- Continue rewriting all tables: correct but 6008 row writes on every unchanged sync
- Trust modification timestamps alone: can miss preserved-timestamp edits
- Filesystem watcher alone: does not reliably cover cross-process and offline edits

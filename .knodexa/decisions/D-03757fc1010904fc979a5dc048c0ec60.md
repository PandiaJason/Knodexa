## Rationale
Use OS-backed bounded file locks for task mutation and shared index synchronization. SaveTask compares a canonical-content fingerprint and rejects stale snapshots, while mergeable task operations mutate freshly read canonical data under the lock. Do not hold locks across verification commands. Serialize SQLite initialization and configure busy timeout before WAL. Retain original unsafe audit and rerun into a new output folder.

## Rejected alternatives
- Atomic rename alone, which already lost seven of eight writes
- Blindly merging every field, which could resurrect intentionally removed rules
- Holding a memory lock during tests or model calls, which risks deadlock and long blocking

## Rationale
Prior small trials tied. Use a known-correct fixture independently checked before real producers capture memory, then isolated fresh agent returns. A cross-task compatibility convention tests transfer beyond copying the reference; observer panic tests check a recorded failure. Similar APIs challenge identity selection. Refactor changes paths, function names and hashes while requiring explicit stale-agreement reporting.

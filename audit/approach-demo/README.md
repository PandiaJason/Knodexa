# Continuity contract demonstration

This illustrative CLI scenario uses arbitrary workflow names and explicit reuse
links. It switches to unrelated image work, then resumes a separate webhook job
using an established service-injection approach. Names do not determine reuse.

The defective candidate still passes a happy-path functional test but replaces
service delegation with an embedded transformation. The declared approach check
flags that drift. Restoring delegation passes the structural checks; semantic
review remains required. See results.json and drift-context.json.

[memory graph](memory/memory-tree.md) links the generated task AGENTS.md and
SKILL.md snapshots. The source/canonical records in this demo are temporary test
fixtures, not actual production project decisions. Run `python3 audit/approach_demo.py`
to reproduce it with a freshly built binary.

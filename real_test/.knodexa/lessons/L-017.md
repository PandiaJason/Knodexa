## Observation
Reusing buffers in sync.Pool without an explicit Reset() leaks dirty data across invocations. Furthermore, releasing a buffer back to the pool while a caller still references sub-slices causes severe memory corruption.

## Rule
1. Always call buf.Reset() before or immediately after retrieving from the pool.
2. Only return the buffer to the pool after all sub-slice copies are finished.
